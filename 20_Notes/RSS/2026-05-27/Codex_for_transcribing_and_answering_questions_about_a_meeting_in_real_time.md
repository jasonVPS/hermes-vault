Codex for transcribing and answering questions about a meeting in real time: Simon Smith (@_simonsmith) You can now transcribe meetings in real time using Codex and ask Codex questions about meetings as they're happening! I updated my new Codex Meeting Recorder skill to use GPT Realtime Whisper. Tell Codex to use the skill, and it will start transcription and show it in the preview pane. You can ask questions about the transcript as it's being generated. When the meeting's done, tell Codex to end it, and you'll get the full transcript and a formatted version (the formatted version needs work; on my list). Note that because this uses the GPT Realtime Whisper endpoint, it's more expensive than transcribing at the end of the meeting, at $0.017 per minute (so about $0.51 per 30-minute meeting). I'm considering adding a local realtime option in future, such as with Nemotron Speech Streaming. GitHub link is in the thread along with some instructions. — http://nitter.perennialte.ch/_simonsmith/status/2059626873479422250#m
